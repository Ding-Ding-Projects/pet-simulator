# Pet Simulator

A pet collector and pet-care game for Windows. Hatch, raise, feed, groom and evolve — the base
game is complete and free, no loot boxes ever, and no pet ever dies.

**Website:** https://ding-ding-projects.github.io/pet-simulator/

This repository hosts the public website, policies, and (from the first release onward) the
downloadable installers. The game is in active development; no release exists yet.
